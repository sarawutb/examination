**เรียน**: คณะผู้บริหารและหัวหน้าฝ่ายเทคโนโลยีสารสนเทศ สถานศึกษา

## 1. วัตถุประสงค์และภาพรวมการอัปเกรดระบบ (Executive Summary)

เพื่อยกระดับระบบจัดสอบออนไลน์เดิมจากเวอร์ชันเดิม ให้มีประสิทธิภาพ ความเสถียร และความสะดวกในการใช้งานสูงสุดสำหรับครูผู้สอน โดยมุ่งเน้น **การลดระยะเวลาในการสร้างและคีย์ข้อสอบลงกว่า 90%** ผ่านระบบอ่านและนำเข้าไฟล์เอกสารอัตโนมัติ พร้อมระบบตรวจสอบความถูกต้องก่อนนำเข้าจริง (Live Interactive Preview System)

---

## 2. ขอบเขตงานพัฒนาและปรับปรุง (Scope of Work & Features)

### มอดูลที่ 1: ระบบนำเข้าข้อสอบผ่านไฟล์ Microsoft Word (.docx Import Engine)
* **การสกัดข้อมูลอัตโนมัติ**: อ่านโจทย์ ตัวเลือก 1-5 และเฉลยคำตอบจากไฟล์ Word (.docx) ได้ทั้งข้อสอบปรนัยและข้อสอบอัตนัย
* **รองรับโครงสร้างการพิมพ์หลากหลาย**: รองรับทั้งการพิมพ์เรียงข้อแบบ Paragraph และการพิมพ์ลงตาราง (Table Format)
* **Single-Modal Interactive Preview**: แสดงหน้าตารางพรีวิวบนหน้าหลัก ให้ครูผู้สอนสามารถตรวจสอบ แก้ไขข้อความโจทย์ แก้ไขตัวเลือก และสลับตัวเลือกเฉลยได้แบบ Real-time ก่อนยืนยันบันทึกจริง
* **Dynamic Highlight Selection**: แสดงแถบสีเขียวไฮไลท์ตัวเลือกเฉลยโดยอัตโนมัติเมื่อมีการเปลี่ยนตัวเลือกในช่อง Select

### มอดูลที่ 2: ระบบนำเข้าข้อสอบผ่านไฟล์ Excel (.xlsx / .csv Import Engine)
* **การอ่านไฟล์ความเร็วสูง**: รองรับไฟล์ตารางคำนวณ `.xlsx` และ `.csv` อ่านข้อมูลได้อย่างรวดเร็วและปลอดภัย
* **Single-Modal Interactive Preview**: มีระบบพรีวิวและแก้ไขข้อมูลสดเช่นเดียวกับไฟล์ Word
* **แยกไฟล์ Template สแตนดาร์ด**: บริการจัดทำไฟล์ตัวอย่าง Template Word และ Excel แยกตามประเภทข้อสอบ (ปรนัย และ อัตนัย) เพื่อให้อาจารย์ผู้สอนดาวน์โหลดไปใช้งานได้ง่ายดาย

### มอดูลที่ 3: ระบบจัดการชุดข้อสอบกระจายหลายสาขาวิชา (Multi-Branch Exam Series)
* **การจัดสอบหลายสาขาพร้อมกัน (Batch Multi-Select)**: เพิ่มระบบเลือกสาขาวิชาเป้าหมายได้มากกว่า 1 สาขาในการออกชุดข้อสอบครั้งเดียว
* **การจัดกลุ่มชั้นปีและห้องเรียน (Branch Header Grouping)**: จัดกลุ่มห้องเรียนตามหัวข้อสาขาวิชาในหน้าเลือกห้องสอบสำหรับนักเรียน
* **ระบบลบค่าห้องเรียนซ้ำ (Deduplication System)**: ป้องกันปัญหาการแสดงผลห้องเรียนซ้ำซ้อนในตารางแสดงรายการข้อสอบ
